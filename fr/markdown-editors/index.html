Éditeurs Markdown

vendredi 8 novembre 2019
Translated by: gpt-4o-2024-08-06 | Original version

Je suis à la recherche d’un éditeur Markdown approprié. Voici les scénarios d’utilisation et les critères que j’ai en tête :

  • Je prévois de l’utiliser comme éditeur pour écrire mon journal.
  • Je veux que l’éditeur soit agréable
  • Je veux voir les images dans la prévisualisation (ou dans l’éditeur lui-même) immédiatement
  • Je veux du support, par exemple lors de l’entrée du lien vers une image, il devrait me montrer les fichiers image dans le répertoire - au moins aussi bien que VS Code le fait…

Voici les éditeurs que j’ai examinés et les Avantages & Inconvénients :

  • Byword : 🛑 Ne montre pas les images dans la prévisualisation
  • MacDown : 🛑 Montre les images dans la prévisualisation, mais n’a pas de support pour entrer des références aux images et scintille beaucoup : On a l’impression qu’il redessine toute la page à chaque caractère que j’entre… C’est agaçant !

  • Abricotine : A l’air bien, il montre les images. Avantages & Inconvénients :

  • Avantage : Je n’ai qu’une seule fenêtre : l’écriture et la prévisualisation se font dans le même panneau - ce qui est une expérience agréable je pense.

  • Avantage : Il supporte bien l’ajout d’images : Avec un dialogue approprié, même avec des raccourcis 😜
  • Avantage : C’est Open Source
  • Inconvénient : Mes photos prises avec l’iPhone s’affichent à l’envers. Comme de nombreuses applications ont ce problème, je l’attribue à un problème spécifique au Mac - et c’est facile à corriger…

  • Inconvénient : Il se bloque souvent. Cela semble se produire principalement lorsque j’ouvre/crée un nouveau document.

  • Notable : 🛑 Agréable sur Mac, mais pas de prévisualisation d’image ni de support pour l’insertion d’images.

  • Obsidian : C’est une chose totalement différente, je devrai découvrir plus tard…
